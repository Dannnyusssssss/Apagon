# Inventario de privacidad

Qué datos trata Apagón, dónde quedan y cómo se borran.

## Datos personales

Ninguno. El juego no tiene cuentas, formularios, chat, ranking en línea, anuncios ni analítica, no usa cookies y no se conecta a ningún servicio.

## Lo que se guarda en el dispositivo

Se guarda solo en el navegador del jugador, en `localStorage`, con la clave `apagon:v1`. Nunca sale del dispositivo.

| Dato | Para qué |
|---|---|
| Ajustes: reducir parpadeo, silencio, linterna clásica, apuntar con el ratón, controles táctiles y zurdos | Recordar cómo prefiere jugar cada persona |
| Nivel alcanzado | Ofrecer "Continuar" desde ese nivel |
| Mejores tiempos de cada nivel y de la partida completa | Mostrar los récords propios |

Se escribe solo cuando el jugador cambia un ajuste o termina un nivel.

## Terceros

- **Alojamiento:** el juego se sirve desde GitHub Pages. Como cualquier alojamiento web, puede registrar datos técnicos de las visitas, como la dirección IP; el juego no los recibe ni los usa.
- **Portal:** el juego se muestra dentro del portal de su autor, que lo carga en un marco del mismo sitio.

## Cómo borrar los datos

- Borrando los datos del sitio desde la configuración del navegador.
- Desde el portal, con su opción para borrar los datos guardados de este juego.

## Menores

El juego no recoge datos de nadie, tampoco de menores.
